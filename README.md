# GeoIQ SA: GIS Suitability Platform

A site-selection prototype for South Africa. Candidate sites are scored with weighted multi-criteria decision analysis (MCDA) using population, competition, road access and income, and shown on an interactive map.

**Status:** front-end prototype (single HTML page, Leaflet map). Sample data only.

## My role
Team project. I contributed to the platform (OpenStreetMap data, weighted MCDA, React/Leaflet frontend, FastAPI/PostGIS backend).

## Tools
Leaflet, JavaScript, MCDA, OpenStreetMap, FastAPI, PostGIS, React.
